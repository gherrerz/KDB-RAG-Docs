# Modelo Operativo de Gobierno de Datos

## Responsabilidad, integridad y calidad

La responsabilidad define quien decide y quien ejecuta controles sobre los
datos criticos. La integridad asegura que las reglas de negocio y las claves
de referencia se mantengan consistentes. La calidad mide completitud,
validez y oportunidad para que el dato sirva a decisiones de negocio.

## Roles y stewardship federado

El data governance council patrocina el modelo operativo y delega
stewardship federado en cada dominio. Los roles de data owner, data steward,
arquitectura y riesgo conectan la estrategia con la operacion diaria y con
las politicas de seguridad y privacidad.

## Relacion con la estrategia de datos

La gestion estrategica necesita que responsabilidad, integridad y calidad se
midan con el mismo lenguaje que usa la estrategia de datos. Por eso el
gobierno de datos debe vincular catalogo, datos maestros, controles de
acceso y definiciones de calidad con la analitica de negocio.

## Prioridades de implementacion

Las prioridades mas frecuentes son catalogo comun, datos maestros,
seguridad y privacidad, contratos de datos y monitoreo continuo de calidad.
Sin ese marco, la analitica pierde contexto y los roles no pueden sostener
una mejora durable.
